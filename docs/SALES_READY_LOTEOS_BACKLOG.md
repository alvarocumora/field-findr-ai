# Backlog para dejar lista la venta de planes de gestión de loteos

## Objetivo

Convertir la plataforma en un producto vendible para inmobiliarias que gestionan loteos.

## Fase 1 — Oferta pública

- Página de planes para inmobiliarias.
- Ruta pública `/planes-loteos`.
- CTAs desde landing principal.
- CTAs desde vitrinas públicas de inmobiliarias.
- Copys comerciales y objeciones frecuentes.

## Fase 2 — Captura comercial

- Formulario de demo con plan seleccionado.
- Notificación interna de nuevo interesado.
- Registro en leads o tabla comercial.
- Tracking de origen: landing, vitrina, dashboard, campaña.

## Fase 3 — Checkout

- Stripe o flujo manual de venta asistida.
- Plan seleccionado.
- Confirmación de pago o solicitud de contacto.
- Activación de cuenta/plan.

## Fase 4 — Gating por plan

- Límites por proyectos activos.
- Límites por lotes.
- Límites por usuarios.
- Features premium: dashboard multi-proyecto, proyectos destacados, reportes avanzados.

## Fase 5 — Operación postventa

- Onboarding de inmobiliaria.
- Configuración de vitrina pública.
- Carga inicial de loteos.
- Capacitación comercial.
- Métricas de adopción.

## Prioridad inmediata

1. Mergear página base de pricing.
2. Registrar ruta pública `/planes-loteos`.
3. Agregar CTAs visibles.
4. Crear captura de demo/plan.
5. Conectar checkout o flujo comercial asistido.
