# Fuentes de las fichas PDF

TTF estáticos incrustados por jsPDF al generar dossiers, láminas y fichas
(`src/lib/pdf/fichaFonts.ts`). Se descargan solo al generar un PDF: `.ttf` no
está en los `globPatterns` del precache de la PWA.

- Montserrat (Regular, SemiBold, ExtraBold) — SIL Open Font License 1.1
- Caveat (SemiBold) — SIL Open Font License 1.1

Fuente: Google Fonts.
